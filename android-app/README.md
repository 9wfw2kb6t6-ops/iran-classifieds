# سه‌سوته — Android app

این اپ با Expo و React Native ساخته می‌شود و به API عمومی سایت سه‌سوته متصل است.

## اجرای محلی

نیازمندی‌ها: Node.js نسخه LTS و حساب Expo.

```bash
cd android-app
npm install
npx expo start
```

برای باز کردن روی گوشی اندروید، Expo Go را نصب و QR نمایش‌داده‌شده را اسکن کنید.

## ساخت APK آزمایشی

```bash
npm install
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

پس از پایان ساخت، EAS لینک دریافت APK را ارائه می‌کند.

## وضعیت فعلی

- صفحه اصلی فارسی و راست‌چین
- دریافت فهرست آگهی‌های منتشرشده از `/api/listings`
- جست‌وجوی محلی عنوان آگهی
- نمایش عکس، قیمت، شهر و دسته‌بندی
- به‌روزرسانی با کشیدن صفحه به پایین

## مراحل بعدی

1. بررسی و تکمیل احراز هویت موبایل با API امن و session مناسب اپ
2. صفحه جزئیات آگهی
3. ثبت آگهی و انتخاب عکس
4. حساب کاربری و مدیریت آگهی‌ها
5. پیام‌ها و اعلان‌ها
6. تست نهایی و انتشار

**توجه:** این نسخه هنوز APK نهایی یا اپ آماده انتشار نیست. احراز هویت و ثبت آگهی از داخل اپ هنوز پیاده‌سازی نشده‌اند. هیچ رمز یا کلید محرمانه‌ای نباید داخل اپ قرار بگیرد.
