# اپ سه‌سوته

اپلیکیشن با Expo و React Native ساخته می‌شود و از API مشترک سایت استفاده می‌کند. سایت و اپ به یک دیتابیس، حساب کاربری، آگهی‌ها، کیف پول و درخواست‌های فروشگاه‌ساز متصل هستند.

## امکانات پیاده‌سازی‌شده

- صفحه اصلی با فهرست آگهی‌های منتشرشده
- جست‌وجو بر اساس عنوان، شهر، دسته‌بندی و محدوده قیمت
- جزئیات آگهی، تماس و واتساپ با آگهی‌دهنده
- گزارش آگهی با همان API گزارش سایت
- ورود و ثبت‌نام با شماره موبایل و رمز عبور؛ نشست امن موبایل در SecureStore
- حساب مشترک با سایت و مدیریت آگهی‌ها
- ثبت آگهی و بارگذاری عکس‌ها در فضای ذخیره‌سازی مشترک
- کیف پول و درخواست شارژ مشترک
- درخواست آگهی ویژه و نردبان با تعرفه‌های API سایت
- فروشگاه‌ساز، پیگیری درخواست‌ها، پیام با تیم و تأیید طرح/تحویل

## اجرای محلی

نیازمندی‌ها: Node.js نسخه ۲۰ یا بالاتر و Expo Go.

```bash
cd android-app
npm install
npx expo start
```

## ساخت APK آزمایشی اندروید

```bash
cd android-app
npm install
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

## ساخت نسخه iOS

پروژه برای iOS نیز پیکربندی شده است. ساخت و انتشار نسخه iOS به حساب Apple Developer و تنظیمات امضای اپل نیاز دارد.

## نکات اتصال

- نشانی API در `lib/api.ts` تنظیم شده است.
- هیچ دیتابیس جداگانه‌ای برای اپ وجود ندارد.
- نشست موبایل در حافظه امن دستگاه نگهداری می‌شود و سرور آن را با همان منطق حساب سایت اعتبارسنجی می‌کند.
- پرداخت آنلاین کیف پول تا زمان فعال شدن درگاه، فقط درخواست شارژ ثبت می‌کند و پرداختی انجام نمی‌دهد.
- سرویس پیامک OTP هنوز به پروژه متصل نشده است؛ ورود فعلی با رمز عبور انجام می‌شود.

## وضعیت انتشار

کدهای اپ در مخزن ثبت شده‌اند، اما APK نهایی هنوز ساخته و روی دستگاه واقعی آزمایش نشده است. قبل از انتشار باید بررسی خودکار TypeScript و خروجی Expo موفق شود و ورود، ثبت آگهی و بارگذاری عکس در دستگاه واقعی تست شوند.
